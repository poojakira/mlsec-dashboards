Architecture specification — not a running platform · Source repo ↗
This is an architecture specification, not a running system. The design integrates all 7 detectors behind a FastAPI gateway with Prometheus metrics and Grafana dashboards. The Docker Compose file exists and health checks are wired, but end-to-end integration tests do not yet pass. "77 finding types → 100+ ATT&CK mappings" is a design target, not a measured result.
